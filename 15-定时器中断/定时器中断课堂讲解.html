六步总览

前 5 步写在初始化函数里、main 开头调用一次；第 6 步是中断服务函数，时间一到硬件自动跳进去，不用你调。

1
打开中断总开关 EA = 1;
所有中断的总闸门，不开它，后面全白配。
2
允许定时器0中断 ET0 = 1;
EA 只管总闸，每个中断源还要单独开自己的门。
3
选工作模式 TMOD &= 0xF0; TMOD |= 0x01;
低4位管定时器0，设成模式1（16位）。本页重点详解 ↓
4
装初值 TL0 = 64614; TH0 = 64614 >> 8;
初值决定定时多长。本页重点详解 ↓
5
启动定时器 TR0 = 1;
开始数机器周期，数满就溢出。
6
写中断服务函数 void 名字() interrupt 1 { ... }
每定时时长自动进来一次：重装初值 + 业务代码。

3选工作模式：TMOD 在配什么

TMOD 是 1 个 8 位寄存器：高 4 位管定时器1，低 4 位管定时器0。我们只用 T0，所以只动低 4 位。

TMOD 位结构（当前 = 0x01）

← 高4位：定时器1（本工程不动它）
低4位：定时器0（本工程在配它）→
TMOD = 0000 0001 0x01 模式1：16位定时器
当前 M1M0 = 01 → 模式1（16位）：TH0 和 TL0 拼成一个 16 位计数器，从初值数到 65536 溢出，单次最长 65.536ms，是最常用的模式。

点按钮切换模式，看 M1M0 变化

模式M1 M0计数器位数单次最长定时（12MHz）特点
00013 位8.192ms老古董，兼容旧设计
10116 位65.536ms最常用：范围大、好算
2108 位256μs硬件自动重装初值，误差小，适合精确短定时

这两行代码到底在干什么

用「位掩码」思想：&= 清位（把要改的位清零）、|= 置位（把需要的位写成 1），同时不碰其他位。

// 初始：复位后 TMOD = 0x00，即 0000 0000
TMOD &= 0xF0;   // ① 与 1111 0000 相与 → 低4位清零，高4位原样保留
TMOD |= 0x01;   // ② 或 0000 0001 → M0 置1，低4位变成 0001
① TMOD &= 0xF0; —— 清掉低4位
  TMOD  0000 0000   （假设原来是 0x00）
& 0xF0  1111 0000
──────────────
=        0000 0000   → 低4位全变 0，高4位不动
为什么不直接 TMOD = 0x01？如果之前配过定时器1（高4位有值），直接赋值会把它冲掉；&= 只改低4位、保住高4位。
② TMOD |= 0x01; —— M0 置 1
  TMOD  0000 0000
| 0x01  0000 0001
──────────────
=        0000 0001   → M1M0 = 01 → 模式1（16位）
等价写法：TMOD = (TMOD & 0xF0) | 0x01;（一步完成，意思完全一样）。如果保证不用定时器1，也可以直接 TMOD = 0x01;。

4装初值：TH0 / TL0 决定定时多长

16 位计数器从初值开始，每个机器周期 +1，数到 65536 就溢出、触发中断。所以：初值 = 65536 − 想数的机器周期数。初值越大，离溢出越近，定时越短。

64614 拆开看：一个数，三种写法

十进制    64614
十六进制  0xFC66
二进制    1111 1100 0110 0110
         └──TH0──┘ └─TL0─┘
         高8位     低8位
TH0 = 1111 1100 = 0xFC = 252
对应 64614 的二进制高 8 位（前 8 个 bit）
TL0 = 0110 0110 = 0x66 = 102
对应 64614 的二进制低 8 位（后 8 个 bit）
验证：252 × 256 + 102 = 64512 + 102 = 64614，成立。
口诀：TH0 × 256 + TL0 把两个 8 位拼回原来的 16 位数。

为什么代码要写两行，而不是一行

TH0 和 TL0 都是 8 位寄存器，一次只能装 8 位（0~255）。64614 是 16 位数，必须拆成两半分别装。

TL0 = 64614;          // TL0 只有 8 位：编译器自动只取低 8 位 → 0x66
TH0 = 64614 >> 8;      // 右移 8 位：把高 8 位挪到低 8 位 → 0xFC
>> 8 右移示意
64614      = 0xFC66 = 1111 1100 0110 0110
64614 >> 8 = 0x00FC = 0000 0000 1111 1100
                          └─ 原来的高8位跑到了这里，低8位被丢
所以 TH0 = 0xFC
TL0 自动截断
TL0 = 64614;   // TL0 是 8 位寄存器（unsigned char）
              // 64614 = 0xFC66，编译器自动丢掉高 8 位
              // TL0 = 0x66
两种写法等价：TL0 = 64614; TH0 = 64614 >> 8; 和 TL0 = 0x66; TH0 = 0xFC; 效果一样。初学者建议先算好十六进制，再用 >> 8 写，不容易错。

定时时长反推（12MHz）

// 89C52 是 12T 单片机：机器周期 = 12 ÷ 晶振频率 = 12 ÷ 12MHz = 1μs
// 模式1：一次溢出定时 = (65536 − 初值) × 机器周期
定时时间 = (65536 − 64614) × 1μs = 922μs ≈ 0.922ms

// 本工程现象：
// 每 0.922ms 进一次中断，count 数到 5000 才翻转 LED
翻转间隔 ≈ 0.922ms × 5000 ≈ 4.6 秒

上课常踩的坑

① 模式1 必须软件重装初值
中断函数里要再写一次 TH0 / TL0，否则下一次定时时长错乱。模式2 才由硬件自动重装。
② 不要手动调用 interrupt 函数
中断函数由硬件自动调用。本工程 main() 的 while(1) 里调了 Dir_Timer0_Handler()，会让翻转明显变快；改成 while(1); 空循环即可。
③ 计数变量用 static 或全局
函数里的普通局部变量每次进入都会重新初始化，count 永远数不到 5000。
④ 中断服务函数要短
别在里面做长延时或复杂计算，否则会拖慢主程序，实时性变差。
⑤ 先算再写，别凭感觉填初值
初值差 1，定时就差 1μs；要定时 1ms 就写 64536，不要写成 64614 还当 1ms。
记忆锚点（12MHz）
机器周期 1μs → 模式1 初值 = 65536 − 微秒数 → 除以 256 得 TH0，余数得 TL0。
