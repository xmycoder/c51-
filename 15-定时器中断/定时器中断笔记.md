# 定时器中断使用笔记（89C52 · 定时器0）

> 适用：STC89C5x / 89C52，SDCC 编译，12MHz 晶振（12T 模式）。
> 配套工程：本目录 `project`，现象为 P2.0 的 LED 大约每 4.6 秒翻转一次。

---

## 一、怎么用：六步流程

| 步骤 | 做什么 | 代码 | 说明 |
|---|---|---|---|
| 1 | 打开中断总开关 | `EA = 1;` | 所有中断的总闸门，必须开 |
| 2 | 打开定时器0中断开关 | `ET0 = 1;` | 只允许定时器0发中断 |
| 3 | 选工作模式 | `TMOD &= 0xF0; TMOD |= 0x01;` | 低4位管T0，模式1 = 16位定时 |
| 4 | 装初值 | `TL0 = 64614; TH0 = 64614 >> 8;` | 决定定时多长 |
| 5 | 启动定时器 | `TR0 = 1;` | 开始计数 |
| 6 | 写中断服务函数 | `void xxx() interrupt 1 { ... }` | 时间到自动进来执行 |

对应本工程的初始化代码：

```c
void Dir_Timer0_Init()
{
    EA = 1;                 // 第1步：开中断总开关
    ET0 = 1;                // 第2步：允许定时器0中断

    TMOD &= 0xF0;           // 第3步：清掉低4位（T0的配置位）
    TMOD |= 0x01;           //       置为 0001：模式1（16位定时器）

    TL0 = 64614;            // 第4步：装初值（十进制，自动截取低8位）
    TH0 = 64614 >> 8;       //       取高8位

    TR0 = 1;                // 第5步：启动定时器
}
```

第6步的中断服务函数（时间一到硬件自动跳进来）：

```c
void Dir_Timer0_Handler() interrupt 1   // interrupt 1 = 定时器0
{
    static unsigned int count = 0;      // 计数变量要 static 或全局

    TL0 = 64614;                        // 模式1必须软件重装初值！
    TH0 = 64614 >> 8;

    count++;                            // 业务：计数
    if (count >= 5000)
    {
        P20 = ~P20;                     // 翻转 LED
        count = 0;
    }
}
```

## 二、定时时长怎么算

```
机器周期 = 12 ÷ 晶振频率          （89C52 是 12T 单片机）
定时时间 = (65536 − 初值) × 机器周期
初值     = 65536 − (定时时间 ÷ 机器周期)
```

12MHz 晶振下：机器周期 = 1μs，一次中断时间 = `65536 − 初值` 微秒。

**12MHz 常见初值速查表**

| 想要定时 | 计数个数 | 初值(十进制) | 初值(十六进制) |
|---|---|---|---|
| 0.922ms（本工程） | 922 | 64614 | 0xFC66 |
| 1ms | 1000 | 64536 | 0xFC18 |
| 5ms | 5000 | 60536 | 0xEC78 |
| 10ms | 10000 | 55536 | 0xD8F0 |
| 50ms | 50000 | 15536 | 0x3CB0 |

超过 65.536ms 的定时，模式1装不下，用计数器累加实现（像本工程 count 到 5000 再翻转）。

---

## 三、本工程现象推算

- 初值 64614 → 65536 − 64614 = 922 → 一次中断 ≈ 0.922ms
- count 数到 5000 才翻转 LED → 0.922ms × 5000 ≈ **4.6 秒翻转一次**

## 五、寄存器速查

**IE 中断允许寄存器**

| 位 | 名称 | 作用 |
|---|---|---|
| 7 | EA | 中断总开关 |
| 4 | ES | 串口中断允许 |
| 3 | ET1 | 定时器1中断允许 |
| 2 | EX1 | 外部中断1允许 |
| 1 | ET0 | **定时器0中断允许** |
| 0 | EX0 | 外部中断0允许 |

**TMOD（低4位管 T0，高4位管 T1）**

| 位 | 名称 | 作用 |
|---|---|---|
| 3 | GATE | 门控位，0 = 仅由 TR0 控制 |
| 2 | C/T | 0 = 定时（数机器周期），1 = 计数（数外部脉冲） |
| 1:0 | M1 M0 | 00=模式0(13位) 01=**模式1(16位)** 10=模式2(8位自动重装) 11=模式3(拆分) |

**TCON**

| 位 | 名称 | 作用 |
|---|---|---|
| 5 | TF0 | 溢出标志，时间到置1并触发中断（进中断后硬件自动清零） |
| 4 | TR0 | **启动/停止定时器0** |

## 六、常见坑

1. **模式1必须软件重装初值**：中断函数里要再写一次 `TH0/TL0`，否则下次定时时长不对。
2. **不要在 main 里手动调用 interrupt 函数**：中断函数由硬件自动调用。本工程 `main()` 的 `while(1)` 里调了 `Dir_Timer0_Handler()`，会导致翻转明显变快；改成 `while(1);` 空循环即可，中断自己会进来。
3. **计数变量用 static 或全局**：函数里的普通局部变量每次进入都会重新初始化。
4. **中断服务函数要短**：别在里面做长时间延时，会影响主程序。
5. **精确计时用模式2（8位自动重装）**：不用手动重装、误差小，但单次最长只有 256 个机器周期，适合短定时。
