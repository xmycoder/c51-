学习目标：知道 DS1302 是干什么的、8 个引脚各接什么、和 51 怎么连。

DS1302 就像一块用纽扣电池一直供着电的电子表：单片机断电它也照走，51 通过 3 根线随时去"看表"（读时间）和"对表"（设时间）。

与 51 的接线（本工程）

VCC2 ← 5V 主电 · VCC1 ← 3V 纽扣电池 · X1–X2 之间接 32.768kHz 晶振（无需外部电容）· 与单片机共地

本关要点

  • 三根线：CE（使能，高电平传输）· SCLK（时钟）· I/O（数据）。
  • 晶振：必须 32.768kHz、负载电容 6pF，内部振荡器不需要外部电阻电容。
  • 双电源：VCC2 接 5V 主电，VCC1 接 3V 纽扣电池；VCC2 > VCC1+0.2V 时自动用主电，断电自动切电池（维持电流不到 1µA）。

  • 写命令 = 0x80 | (地址<<1)，读命令 = 写命令 + 1；RAM 把 bit6 置 1。

陷阱 ① 写保护 WP —— "写了没反应"

芯片上电时 WP 状态不确定（常见为 1）。WP=1 时除 0x8E 自己以外的所有寄存器拒绝写入，而且读不受影响——软件毫无报错，极具迷惑性。

陷阱 ② CH 停振位 —— "写进去了但时间不走"

秒寄存器 bit7 是 CH（Clock Halt）：CH=1 振荡器停振、时间冻结（上电状态不确定）。写秒值时 bit7 自然为 0，时钟就走起来了。点下面的按钮试试：

00 CH = 0 · 走时中

陷阱 ③ BCD 码 —— "显示的数字莫名变大"

寄存器里存的是 BCD：高 4 位十位、低 4 位个位。拖动滑块看"不做转换会显示什么"：

附赠陷阱 ④ 读数错位 —— "读回的值像被乘了 2"

把读函数的命令循环写成 SCLK=1; SCLK=0;（先 1 后 0），会在命令最后一位之后多产生一个下降沿：芯片提前吐出 D0，你的读循环却把它当成"上一拍的残留"跳过——读回的 8 位整体错一位。正确写法见第 3 关读时序：命令阶段停在 SCLK=1。

本关要点

  • Init 里必须 写 0x8E ← 0x00（WP 拦不住对它自己的写入，所以这条永远成功）。
  • 读 0x8F 可当通信自检：正常只能读回 0x00 或 0x80。
  • 时间不走查 CH，显示不对查 BCD，数值错位查下降沿数量。

学习目标：看懂修正后的参考驱动（3 个★是关键行），并通过过关测验。

参考驱动（对照工程 src/DS1302.C）

#include <STC89C5xRC.H>

sbit DS1302_SCLK = P3 ^ 6;
sbit DS1302_IO   = P3 ^ 4;
sbit DS1302_CE   = P3 ^ 5;

void DS1302_Init(void)
{
    DS1302_CE   = 0;
    DS1302_SCLK = 0;
    DS1302_WriteByte(0x8E, 0x00);   /* ★1 清写保护 WP=0，否则一切写入被忽略 */
}

void DS1302_WriteByte(unsigned char Command, unsigned char Data)
{
    unsigned char i;
    DS1302_CE = 1;
    for (i = 0; i < 8; i++) {            /* 命令字节：LSB 先行 */
        DS1302_IO = Command & (0x01 << i);  /* 先放数据（上升沿前建立） */
        DS1302_SCLK = 1;                 /* 上升沿：芯片锁入 */
        DS1302_SCLK = 0;                 /* 回低，准备下一位 */
    }
    for (i = 0; i < 8; i++) {            /* 数据字节：同样 8 个上升沿 */
        DS1302_IO = Data & (0x01 << i);
        DS1302_SCLK = 1;
        DS1302_SCLK = 0;
    }
    DS1302_CE = 0;                       /* SCLK 已为低，安全结束 */
}

unsigned char DS1302_ReadByte(unsigned char Command)
{
    unsigned char i, Data = 0x00;
    DS1302_CE = 1;
    for (i = 0; i < 8; i++) {            /* 命令阶段：0→1，结束时 SCLK 停在高 */
        DS1302_IO = Command & (0x01 << i);
        DS1302_SCLK = 0;
        DS1302_SCLK = 1;
    }
        DS1302_IO = 1;                       /* ★2 释放总线：准双向口写 1 才能读 */
    for (i = 0; i < 8; i++) {            /* 读阶段：每个下降沿出一位 */
        DS1302_SCLK = 1;
                DS1302_SCLK = 0;                 /* ★3 下降沿：芯片输出一位，立刻采样 */
        if (DS1302_IO) Data |= (0x01 << i);
    }
    DS1302_CE = 0;
    DS1302_IO = 0;
    return Data;                         /* 返回 BCD 码，显示前要转换 */
}
