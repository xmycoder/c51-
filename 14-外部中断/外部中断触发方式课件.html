头文件 + 引脚定义，先写这两行

所有 51 单片机程序的开头都一样，先抄这两行。

① 头文件 + 引脚#include <reg52.h>              // 拿进单片机的说明书
sbit LED = P2^0;              // 给 P2.0 脚起个名字：LED
#include <reg52.h>
把 51 单片机要用的「说明书」（头文件）拿进来。没有它，IT0、EA 这些名字都不认识。
sbit LED = P2^0;
给 P2 口的第 0 脚起个名字叫 LED。后面写 LED，就是在操作这个引脚。
改
LED 接在哪个脚，就写哪个
接 P1.0 → 写 sbit LED = P1^0;；接 P3.4 → 写 sbit LED = P3^4;
记
起名字只为了方便
LED 这个名字自己起，叫 D1、LIGHT 都行，只要后面一直用同一个名字。
第 2 块 04 / 08

三个开关，一个都不能少

② 三个开关void main()
{
    IT0 = 1;                // ① 触发方式：下降沿（按键用）
    IT1 = 1;
    EX0 = 1;                // ② 分开关：开 INT0
    EX1 = 1;                //    分开关：开 INT1
    EA  = 1;                // ③ 总开关
    while(1);                   // 等中断
}
第 1 步 · 管触发方式 ITx
1 = 下降沿（按一下触发一次）；0 = 低电平（按住一直触发）。按键写 1
IT0 = 1; IT1 = 1;
第 2 步 · 分开关 EXx
这个中断自己的开关：用 INT0 开 EX0，用 INT1 开 EX1。只用一个就只开一个
EX0 = 1; EX1 = 1;
第 3 步 · 总开关 EA
全屋总闸。不开 EA，前面配得再好也白搭，中断永远不会触发
EA = 1;
口诀：IT 管方式 · EX 管开关 · EA 是总闸 · 按键用下降沿写 IT = 1
第 3 块 05 / 08

中断服务函数：中断来了干什么

这一块抄的时候最容易错，注意 interrupt 后面的数字。

③ 中断服务函数// INT0 中断服务函数，中断号 0
void INT0_ISR() interrupt 0
{
    LED = ~LED;                 // 中断来了要干的事：LED 翻转
}
!
interrupt 后面的数字是「固定格式」
INT0 用 0，INT1 用 2。抄代码时数字别改，改错中断就不会触发。
名
函数名字随便起
INT0_ISR 是自己起的名字，叫 deng、kai0 都行；但 interrupt 0 不能变。
事
大括号里写「中断来了要干什么」
本例写 LED = ~LED;（LED 翻转：亮↔灭）。想干别的事，就写别的代码。
用哪个中断引脚固定写法
INT0（按键 K3）P3.2interrupt 0
INT1（按键 K4）P3.3interrupt 2
动手写 06 / 08

照抄模板，改这两处就能用

整段程序就是下面这样。蓝色底是「可以改」的地方，其余照着抄。

#include <reg52.h>
sbit LED = P2^0;              // 改①：LED 接哪个脚就写哪个
void main()
{
    IT0 = 1;                // 三个开关，照抄
    IT1 = 1;
    EX0 = 1;
    EX1 = 1;
    EA  = 1;
    while(1);                   // 等中断
}
// 改②：只用 INT0，就把下面 INT1 的函数删掉
void INT0_ISR() interrupt 0    // 改③：用 INT1 就写 interrupt 2
{
    LED = ~LED;                 // 改④：中断来了要干的事写这里
}
void INT1_ISR() interrupt 2
{
    LED = ~LED;
}
抄
三个开关（IT0/IT1/EX0/EX1/EA）一行都不要删；interrupt 0 / 2 按你用的中断写
抄
只用一个中断：删掉另一个的 ITx、EXx 和函数；想干别的事：改中断函数里的 LED = ~LED;
